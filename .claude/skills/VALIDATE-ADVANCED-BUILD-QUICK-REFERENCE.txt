USAGE
──────────────────────────────────────────────────────────────────────────────
Quick (1-2 min, check only)
  validate-advanced-build --quick

Standard (5-10 min, all checks)
  validate-advanced-build

Verbose with auto-fix (7-15 min)
  validate-advanced-build --verbose --fix

INTERPRETATION
──────────────────────────────────────────────────────────────────────────────
Status:
  ✅ PASS       → Validation succeeded
  ❌ FAIL       → Validation failed
  ⚠️  SKIP       → Validation skipped (--quick mode)

Overall:
  ✅ COMPATIBLE      → All checks passed
  ❌ INCOMPATIBLE    → One or more checks failed
  ⚠️  PARTIAL        → Some checks skipped

Exit Codes:
  0  → All combinations work ✅
  1  → Some combinations broken ❌
  2  → System error ⚠️

PARAMETERS
──────────────────────────────────────────────────────────────────────────────
--quick      : Skip clippy and tests (check only)
--verbose    : Show full command output
--fix        : Auto-fix clippy warnings

WHEN TO USE
──────────────────────────────────────────────────────────────────────────────
Before committing feature-gated code:
  → validate-advanced-build --quick

Before opening PR:
  → validate-advanced-build

Before release:
  → validate-advanced-build --verbose --fix

In CI/CD pipeline:
  → validate-advanced-build
  → Check exit code (0 = pass, 1 = fail, 2 = error)

DEBUGGING FAILURES
──────────────────────────────────────────────────────────────────────────────
See which step fails:
  → validate-advanced-build

Get detailed error info:
  → validate-advanced-build --verbose

Try to auto-fix:
  → validate-advanced-build --fix

Manually check one combination:
  → cargo check --features advanced,autonomic
  → cargo test --lib --features advanced,autonomic
  → cargo clippy --features advanced,autonomic --all-targets -- -D warnings

COMMON ISSUES
──────────────────────────────────────────────────────────────────────────────
Compilation error?
  → Check for conflicting dependency versions in feature combination
  → Look for conditional #[cfg(feature = "...")] code paths
  → Run: validate-advanced-build --verbose

Test failure?
  → Tests may not handle feature combination correctly
  → Run single test: cargo test --lib --features <combo> -- --nocapture
  → Check #[cfg] guards in test code

Clippy warnings?
  → Auto-fix: validate-advanced-build --fix
  → Manual fix: cargo clippy --features <combo> --fix --allow-dirty
